Nazwy skilli Claude Code w vaultcie mają być zawsze po angielsku (kebab-case), np. `start-day`, `meeting`, `tidy-journal`, `compile-notes` — mimo że cała treść vaulta i komunikacja są po polsku.

**Why:** Rafał wprost o to poprosił (2026-07-09) przy projektowaniu skilla porannego rytuału — pierwotna propozycja `start-dnia` została odrzucona na rzecz `start-day`.

**How to apply:** Przy tworzeniu lub zmianie nazwy dowolnego skilla w `.claude/skills/` używaj angielskiego identyfikatora; opis i treść skilla mogą pozostać po polsku.
