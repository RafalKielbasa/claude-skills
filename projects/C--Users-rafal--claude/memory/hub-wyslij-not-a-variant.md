When a hub draft waits for approval, ask only for the literal „wyślij” (role.md:6: "Never send a message to another session before Rafal has seen its exact text and said "wyślij"."). Do not wrap it in the Recommendation-First template as „[A] wyślij / [B] zmień”: Rafal answers "A", which is not "wyślij", and the hub has to ask again.

**Why:** on 2026-10-15 (Plan 3 acceptance, hub-ba) this happened twice; each time an extra round with Rafal. Typos of the word itself ("wyslij", "wyśl;ij") were accepted as "wyślij" and noted for the acceptance report.

**How to apply:** end a draft turn with "⏸ Czeka na decyzję: napisz „wyślij”, …" and, if alternatives matter, say in prose that other wording means a new draft. Lettered variants stay for real choices (D1/D2 answers, which session, etc.). Related: [[hub-confirm-hub-name]].
